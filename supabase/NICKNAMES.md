# 그룹 키워드 닉네임

## 운영 적용

기존 Supabase SQL Editor에서 group-nicknames.sql 전체를 한 번 실행합니다. 기존 사번·점수·순위는 유지합니다. 이전 최고기록 연출용 SQL도 포함되어 있습니다. 새 프로젝트는 최신 schema.sql에 포함되어 있습니다.

TOP 100에 해당하는 등록 완료 코인에서만 새 닉네임을 뽑을 수 있습니다. 수식어 20개 × 키워드 29개 × 번호 10,000개로 580만 조합입니다. 서버가 생성하므로 자유 입력 문자열은 저장하지 않습니다. 확정 전까지 최대 30회 뽑을 수 있고, 확정하면 이벤트·사번별로 유지됩니다. 공개 순위에는 확정된 닉네임을 표시합니다. 아직 선택하지 않은 기존 참가자는 '닉네임 미등록'으로 표시됩니다. 같은 이벤트에서 닉네임 중복을 허용하지 않습니다. 점수는 닉네임 선택과 별도로 먼저 저장됩니다.

전체 사번은 기존 blackhole.coins와 blackhole.best_scores에 유지되며, blackhole.nicknames의 employee_id와 연결됩니다. 공개 API는 전체 사번을 반환하지 않습니다. 관리자 권한으로 해당 테이블을 조회할 수 있습니다. 닉네임을 관리자 변경할 경우 정해진 단어 조합을 사용하세요.

## 키워드 제안 및 반영 풀

- 캐릭터·상징: 무궁이, 무진이, 동아, 동아쏘시오, 쏘시오, 피닉스
- 그룹 회사·친숙한 이름: 동아에코팩, 동아제약, 동아에스티, 에스티팜, 동아오츠카, 용마로지스, 디에이인포메이션, 아벤종합건설
- 동아제약 브랜드: 박카스, 판피린, 챔프, 노스카나, 베나치오, 가그린, 검가드, 모닝케어, 미니막스, 파티온
- 동아오츠카 브랜드: 포카리스웨트, 오로나민C, 데미소다, 오란씨, 나랑드사이다

수석·동천수·에스티젠바이오·홀딩스는 생성 풀에서 제외했습니다. 무궁이·무진이는 사용자가 제공한 프로젝트 캐릭터명입니다. 회사·브랜드명은 닉네임 재료이며 참가자의 실제 소속을 뜻하지 않습니다.

수식어: 반짝이는, 용감한, 빛나는, 날쌘, 든든한, 신나는, 다정한, 당당한, 힘찬, 멋진, 행운의, 꿈꾸는, 도약하는, 비상하는, 별빛의, 우주의, 미래의, 열정의, 희망의, 무적의

예시: 반짝이는 무궁이 · 1932 / 비상하는 피닉스 · 4821 / 힘찬 박카스 · 2026
